About Windows 98 Simulator

Windows 98 Simulator is a free web-based recreation of the classic Windows 98 desktop experience. Built with HTML, CSS, and JavaScript, it runs entirely in your browser — no downloads, no plugins, no installation required.

What's Inside

  • Notepad — text editor with menus, word wrap & auto-save
  • Calculator — full arithmetic with keyboard support
  • Paint — 16-color canvas with pencil, eraser, fill & shapes
  • Minesweeper — Beginner / Intermediate / Expert difficulties
  • Solitaire — Klondike card game
  • Internet Explorer — simulated retro browser
  • MS-DOS Prompt — working command line (dir, cd, tree...)
  • My Computer — file explorer
  • Window manager — drag, resize, minimize, maximize, close
  • Screensaver (starfield) + BSOD easter egg (Ctrl+Alt+Del)
  • Date/Time Properties + taskbar right-click (Cascade/Tile)
  • Start menu + taskbar + live clock + boot screen
